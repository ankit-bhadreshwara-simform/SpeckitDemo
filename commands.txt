/constitution

Create a professional constitution file for a .NET 10 Web API project.

The constitution should define the foundational standards, architecture guidelines, and coding principles for the entire solution to ensure maintainability, scalability, consistency, and ease of onboarding.

Include the following sections:

* Basic project structure(Project.Api, Project.DTO, Project.Database, Project.Utiliry, Project.service, Project.Repository, Project.UnitTest)
* Coding standards and naming conventions
* SOLID principles as mandatory development guidelines
* Repository design pattern with service layer separation
* Proper dependency injection and interface-based design
* .NET 10 as the application framework
* Entity Framework Core using Code-First approach
* SQLite as the default database
* API standards including RESTful conventions, versioning, request/response DTO usage, and standard API response structure
* Common API response model for success and failure cases
* Global exception handling middleware
* Structured logging using ILogger
* Unit testing standards using xUnit and Moq - Write code first then unit test
* Clean architecture and separation of concerns
* Security baseline and validation standards

The generated constitution should be written in a professional markdown format and act as the standard rulebook for all future specifications, plans, tasks, and implementation.
